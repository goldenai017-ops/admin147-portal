## Google Drive арқылы файл жүктеуді баптау

Жоспарлар бөлімі Google Drive API арқылы PDF, Word, Excel және PowerPoint файлдарын екі бөлек Google Drive папкасына жүктейді: тәрбие жоспарлары және мектепішілік бақылау жоспарлары. Құжат түрін таңдау файлдың қай папкаға сақталатынын анықтайды. Қазіргі интерфейс сақталған.

### 1. Google Drive папкасын дайындау
1. Екі папканы қолданыңыз: **Тәрбие жоспарлары** және **Мектепішілік бақылау жоспарлары**.
2. Әр папканың сілтемесіндегі `/folders/` кейінгі мән — оның ID-сі. Бұл порталдың `drive-config.js` файлында екі бөлек ID ретінде орнатылады.
3. Екі папканы да «Бөлісу» арқылы қажетті қызметкерлердің Google аккаунттарына ашыңыз. Жүктейтін қызметкерлерге «Редактор» құқығы қажет.
4. «Жалпыға қолжетімді» режимін қоспаңыз. Құжаттарға қолжетімділік Google Drive рұқсаттарымен басқарылады.

### 2. Google API және OAuth
1. https://console.cloud.google.com/ ашып, Google Cloud жобасын жасаңыз немесе бар жобаны таңдаңыз.
2. **Google Drive API** қосыңыз.
3. **Google Auth Platform / OAuth consent screen** бөлімінде қолданба атауын және байланыс email-ын толтырыңыз. Егер қолданба тест режимінде болса, барлық қызметкерлердің Google аккаунттарын Test users тізіміне қосыңыз.
4. **Clients → Create client → Web application** таңдаңыз.
5. **Authorized JavaScript origins** өрісіне дәл мына origin-ді қосыңыз: `https://goldenai017-ops.github.io`
6. Құрылған OAuth Client ID-ді көшіріңіз. Клиент құпия кілті браузерлік қолданбаға қажет емес және оны жарияламаңыз.

### 3. Портал конфигурациясы
1. Репозиторийдегі `drive-config.js` файлын ашыңыз.
2. `PASTE_GOOGLE_OAUTH_WEB_CLIENT_ID_HERE` орнына OAuth Client ID енгізіңіз.
3. Екі папканың ID-сі `folderIds` ішінде орнатылған: «Тәрбие жоспары» және «Мектепішілік бақылау жоспары». Оларды өзгерту қажет болса, тиісті ID-лерді осы объектіде жаңартыңыз.
4. Commit жасаңыз. GitHub Pages жаңарғаннан кейін сайтта «Тәрбие бөлімі» → «Жоспарлар мен мектепішілік бақылау» блогында **Google Drive-ты қосу** батырмасын басыңыз.
5. Google аккаунтын таңдап, рұқсат сұрауын растаңыз. Файлды таңдап, құжат түрін белгілеңіз де жүктеңіз.

## Қолжетімділік және қауіпсіздік
- Файлдардың нақты қолжетімділігі Google Drive папкасының рұқсаттарымен басқарылады; интерфейстегі рөл атаулары қауіпсіздік шектеуі болып саналмайды.
- OAuth токені тек ағымдағы бет жадысында ұсталады және `localStorage` ішіне жазылмайды.
- Бұл сайт GitHub Pages-та ашық жарияланған. Құпия немесе оқушылардың дербес деректері бар құжаттарды осы Drive папкасына жүктемес бұрын мектептің деректерді қорғау талаптарын тексеріңіз.
- Интеграция Google OAuth арқылы `https://www.googleapis.com/auth/drive` ауқымын сұрайды. Google бұл ауқым үшін қосымша consent-screen баптауларын, тестілеуді немесе қолданба тексеруін талап етуі мүмкін.
- Қазір файлдарды жүктеу және ортақ папкадан оқу қарастырылған; сайттың басқа бөлімдеріндегі тапсырмалар/күнтізбе деректері бұрынғыдай браузерде сақталады және өздігінен қызметкерлер арасында синхрондалмайды.

## Файл түрлері
PDF, DOC, DOCX, XLS, XLSX, PPT және PPTX. Бір файлға ең көбі 20 МБ.

## ЖИ арқылы жоспарларды талдау және күнтізбеге бекіту

Жоспарлар бөліміндегі «Жоспарларды талдау» батырмасы екі папкадан ең соңғы қолдау көрсетілетін файлды оқиды, іс-шараларды ЖИ-ге талдауға жібереді және алдымен тексеруге көрсетеді. Күндер мен атауларды түзетіп, қажетті іс-шараларды белгілеп, «Бекіту және күнтізбеге енгізу» батырмасын басқанда ғана олар басты беттегі және күнтізбе бөліміндегі тізімге қосылады.

Қолдау көрсетілетін форматтар: мәтіндік PDF (сканерленген емес), DOCX, XLSX және Google Docs/Sheets. Ескі DOC/PPT файлдарын алдымен DOCX/XLSX/PDF форматына ауыстырыңыз. Әр папкадан соңғы өзгертілген қолдау көрсетілетін бір файл талданады.

### Қауіпсіз AI endpoint орнату (Cloudflare Worker + Gemini)

API кілтін ешқашан index.html немесе drive-config.js ішіне жазбаңыз. Репозиторийдегі ai-worker.js Gemini кілтін Cloudflare Worker Secret ретінде сақтауға арналған. Worker Google аккаунтын тексереді және ALLOWED_EMAILS тізіміндегі аккаунттарға ғана рұқсат береді.

1. Google AI Studio арқылы Gemini API кілтін жасаңыз: https://aistudio.google.com/app/apikey
2. Cloudflare Dashboard → Workers & Pages → Create → Worker ашыңыз.
3. Репозиторийдегі ai-worker.js мазмұнын Worker редакторына көшіріп, Deploy жасаңыз.
4. Worker Settings → Variables and Secrets бөлімінде мынаны орнатыңыз:
   - Secret GEMINI_API_KEY — Google AI Studio кілті.
   - Variable ALLOWED_EMAILS — рұқсат етілген Google аккаунттары, үтірмен бөлінген. Мысалы: ala147gymnasium@gmail.com,teacher@example.com.
5. Worker-дің workers.dev HTTPS URL мекенжайын көшіріңіз.
6. GitHub-та drive-config.js файлын ашып, aiEndpoint бос мәніне Worker URL-ін қойыңыз.
7. Google Cloud → Google Auth Platform → Audience бөлімінде қызметкерлер Test users ретінде қосылғанын тексеріңіз. Drive папкаларына да сол аккаунттарға рұқсат берілуі керек.
8. Сайтты жаңартып, Google Drive-ты қосыңыз. Жоспарлар бөлімінде ЖИ талдау батырмасы қолжетімді болады.

**Маңызды:** GitHub Pages — ашық сайт. ЖИ талдауы рұқсат етілген Google аккаунттарымен шектеледі, бірақ мақұлданған күнтізбе оқиғалары әзірге осы браузердің localStorage қоймасында сақталады және басқа компьютерлермен автоматты синхрондалмайды. Ортақ күнтізбені барлық қызметкерге синхрондау үшін бөлек ортақ сақтау қызметін қосу қажет. Жеке деректері бар жоспарларды AI қызметіне жібермес бұрын мектептің деректерді қорғау талабын тексеріңіз.
