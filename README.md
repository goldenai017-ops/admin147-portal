## Google Drive арқылы файл жүктеуді баптау

Жоспарлар бөлімі Google Drive API арқылы PDF, Word, Excel және PowerPoint файлдарын ортақ Google Drive папкасына жүктейді. Қазіргі интерфейс сақталған; жүктеу блогы «Тәрбие бөлімі» бетіне қосылды.

### 1. Google Drive папкасын дайындау
1. Google Drive-та гимназияның жұмыс құжаттарына арналған папка жасаңыз.
2. Папканы ашып, URL мекенжайындағы `/folders/` кейінгі мәнді көшіріңіз — бұл `folderId`.
3. «Бөлісу» арқылы қызметкерлердің Google аккаунттарын қосыңыз. Әрқайсына қажетті рөлді ғана беріңіз: «Көруші», «Пікір қалдырушы» немесе «Редактор».
4. «Жалпыға қолжетімді» режимін қоспаңыз. Бұл папкаға рұқсаты жоқ адамдар файлдарды аша алмауы керек.

### 2. Google API және OAuth
1. https://console.cloud.google.com/ ашып, Google Cloud жобасын жасаңыз немесе бар жобаны таңдаңыз.
2. **Google Drive API** қосыңыз.
3. **Google Auth Platform / OAuth consent screen** бөлімінде қолданба атауын және байланыс email-ын толтырыңыз. Егер қолданба тест режимінде болса, барлық қызметкерлердің Google аккаунттарын Test users тізіміне қосыңыз.
4. **Clients → Create client → Web application** таңдаңыз.
5. **Authorized JavaScript origins** өрісіне дәл мына origin-ді қосыңыз: `https://goldenai017-ops.github.io`
6. Құрылған OAuth Client ID-ді көшіріңіз. Клиент құпия кілті браузерлік қолданбаға қажет емес және оны жарияламаңыз.

### 3. Портал конфигурациясы
1. Репозиторийдегі `drive-config.js` файлын ашыңыз.
2. `PASTE_GOOGLE_OAUTH_WEB_CLIENT_ID_HERE` орнына OAuth Client ID енгізіңіз.
3. `PASTE_SHARED_GOOGLE_DRIVE_FOLDER_ID_HERE` орнына ортақ папканың ID-сін енгізіңіз.
4. Commit жасаңыз. GitHub Pages жаңарғаннан кейін сайтта «Тәрбие бөлімі» → «Жоспарлар мен мектепішілік бақылау» блогында **Google Drive-ты қосу** батырмасын басыңыз.
5. Google аккаунтын таңдап, рұқсат сұрауын растаңыз. Файлды таңдап, құжат түрін белгілеңіз де жүктеңіз.

## Қолжетімділік және қауіпсіздік
- Файлдардың нақты қолжетімділігі Google Drive папкасының рұқсаттарымен басқарылады; интерфейстегі рөл атаулары қауіпсіздік шектеуі болып саналмайды.
- OAuth токені тек ағымдағы бет жадысында ұсталады және `localStorage` ішіне жазылмайды.
- Бұл сайт GitHub Pages-та ашық жарияланған. Құпия немесе оқушылардың дербес деректері бар құжаттарды осы Drive папкасына жүктемес бұрын мектептің деректерді қорғау талаптарын тексеріңіз.
- Интеграция Google OAuth арқылы `https://www.googleapis.com/auth/drive` ауқымын сұрайды. Google бұл ауқым үшін қосымша consent-screen баптауларын, тестілеуді немесе қолданба тексеруін талап етуі мүмкін.
- Қазір файлдарды жүктеу және ортақ папкадан оқу қарастырылған; сайттың басқа бөлімдеріндегі тапсырмалар/күнтізбе деректері бұрынғыдай браузерде сақталады және өздігінен қызметкерлер арасында синхрондалмайды.
